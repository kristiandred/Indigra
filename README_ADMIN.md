# Админ-панель ИНДИГРА - Инструкция по установке и использованию

## Обзор

Админ-панель позволяет администратору:
- Редактировать содержимое ячеек Excel таблиц
- Добавлять/удалять строки и столбцы
- Создавать новые таблицы
- Удалять существующие таблицы
- Все изменения автоматически сохраняются в Excel файлах и коммитятся в Git

## Установка

### 1. Установка Node.js

Убедитесь, что у вас установлен Node.js (версии 16 или выше):
```bash
node --version
npm --version
```

Если не установлен, скачайте с [https://nodejs.org](https://nodejs.org)

### 2. Установка зависимостей

В папке проекта выполните:
```bash
npm install
```

### 3. Настройка Git

Убедитесь, что Git настроен:
```bash
git config --global user.name "Ваше Имя"
git config --global user.email "ваш.email@example.com"
```

## Запуск

### 1. Запуск сервера

```bash
npm start
```

Или для разработки:
```bash
npm run dev
```

Сервер запустится на порту 3000.

### 2. Доступ к админ-панели

Откройте в браузере:
```
http://localhost:3000/admin-panel.html
```

## Авторизация

Для входа в админ-панель используйте страницу:
```
http://localhost:3000/AutorithAdmin.html
```

По умолчанию:
- Логин: `admin`
- Пароль: `admin123`

## Функционал

### Редактирование таблиц

1. **Загрузка таблиц**: Все `.xlsx` файлы из папки `data/` загружаются автоматически
2. **Редактирование ячеек**: Кликните по ячейке для редактирования
3. **Добавление строк**: Нажмите кнопку "Добавить строку" под таблицей
4. **Удаление строк**: Нажмите ❌ в конце строки
5. **Добавление столбцов**: Нажмите ➕ в заголовке столбца
6. **Удаление столбцов**: Нажмите ❌ в заголовке столбца

### Создание новых таблиц

1. Нажмите "Новая таблица" в навигации
2. Заполните форму:
   - Название файла (без .xlsx)
   - Название таблицы
   - Количество столбцов
   - Количество строк
3. Нажмите "Создать"

### Сохранение изменений

- **Автоматическое сохранение**: Изменения сохраняются при редактировании ячеек
- **Сохранение таблицы**: Нажмите "Сохранить" в заголовке таблицы
- **Git коммиты**: Все изменения автоматически коммитятся в Git

### Удаление таблиц

1. Нажмите "Удалить" в заголовке таблицы
2. Подтвердите удаление в модальном окне
3. Файл `.xlsx` будет удален из папки `data/`

## API эндпоинты

- `GET /api/files` - Получить список Excel файлов
- `GET /api/file/:filename` - Получить содержимое файла
- `POST /api/file/:filename` - Сохранить файл
- `POST /api/file` - Создать новый файл
- `DELETE /api/file/:filename` - Удалить файл

## Безопасность

- Админ-панель защищена авторизацией
- Сессии хранятся в localStorage и sessionStorage
- Время жизни сессии: 30 дней

## Troubleshooting

### Ошибка "EADDRINUSE: address already in use"
Порт 3000 уже занят. Измените порт в `server.js` или остановите другой процесс.

### Ошибка "Ошибка загрузки файлов"
Проверьте:
1. Сервер запущен
2. Папка `data/` существует
3. Файлы имеют расширение `.xlsx`

### Git ошибки
Убедитесь:
1. Git инициализирован: `git init`
2. Настроены имя и email
3. Есть права на запись в репозиторий

## Разработка

Для внесения изменений:
1. Отредактируйте файлы
2. Перезапустите сервер (если используется `npm run dev`)
3. Проверьте изменения в браузере

## Поддержка

При возникновении проблем:
1. Проверьте консоль браузера на ошибки
2. Проверьте логи сервера в терминале
3. Убедитесь, что все зависимости установлены

# Админ-панель редактирования Excel файлов

## Функционал

- ✅ Редактирование ячеек таблиц Excel
- ✅ Добавление/удаление строк и столбцов  
- ✅ Автоматическое сохранение изменений
- ✅ Синхронизация с GitHub
- ✅ Индикаторы статуса сохранения
- ✅ Создание новых таблиц

## 🚀 Быстрый старт (решение проблемы CORS)

### Вариант 1: Offline версия (рекомендуется для тестирования)

Откройте файл `admin-panel-offline.html` в браузере - эта версия работает без сервера и содержит встроенные примеры данных.

### Вариант 2: Локальный сервер

**На Windows:**
```bash
# Просто запустите файл
start-server.bat
```

**На macOS/Linux:**
```bash
python server.py
```

Затем откройте http://localhost:8000/admin-panel-standalone.html

### Вариант 3: Любой HTTP сервер

```bash
# Если установлен Python 3
python -m http.server 8000

# Если установлен Node.js
npx serve .

# Если установлен PHP
php -S localhost:8000
```

## Установка и настройка (полная версия)

### 1. Установка зависимостей PHP

```bash
# Установите Composer если еще не установлен
# Затем выполните в папке проекта:
composer install
```

### 2. Настройка GitHub токена

1. Создайте Personal Access Token на GitHub:
   - Перейдите в Settings → Developer settings → Personal access tokens
   - Создайте токен с правами `repo`
   
2. Откройте файл `sync_github.php`
3. Замените `YOUR_GITHUB_TOKEN` на ваш токен:

```php
$githubToken = 'ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx';
```

### 3. Настройка прав доступа

Убедитесь что у веб-сервера есть права на запись в папку `data/`:

```bash
chmod 755 data/
```

### 4. Настройка веб-сервера

Файлы должны быть доступны через веб-сервер (Apache/Nginx) с поддержкой PHP.

## Использование

1. Откройте `admin-panel.html` в браузере
2. Войдите в систему (если требуется авторизация)
3. Редактируйте таблицы:
   - Кликните на ячейку для редактирования
   - Используйте кнопки ➕/❌ для добавления/удаления столбцов
   - Используйте кнопку "Добавить строку" для новых строк
4. Изменения автоматически сохраняются через 2 секунды
5. Статус синхронизации отображается в заголовке таблицы

## Возможные проблемы

### Ошибка "Файл не найден"
- Проверьте что файл существует в папке `data/`
- Убедитесь что права доступа установлены корректно

### Ошибка синхронизации с GitHub
- Проверьте токен GitHub
- Убедитесь что у токена есть права `repo`
- Проверьте подключение к интернету

### Ошибка сохранения
- Убедитесь что установлены зависимости Composer
- Проверьте права записи в папку `data/`
- Проверьте что PHP имеет доступ к библиотеке PhpSpreadsheet

## Автосохранение

Изменения автоматически сохраняются:
- Через 2 секунды после редактирования ячейки
- Сразу после добавления/удаления строк или столбцов
- При нажатии кнопки "Сохранить"

## Синхронизация с GitHub

- Автоматическая синхронизация после успешного сохранения
- Ручная синхронизация через кнопку "Синхронизировать"
- Статус синхронизации отображается в реальном времени
